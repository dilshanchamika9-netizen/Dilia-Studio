How to Remove a Password From a PDF You Own

A PDF that asks for a password every time you open it is annoying, especially if you open it often or need to merge or edit it. If you know the password, you can save a copy that opens without one. Remove password does that in your browser.

Open Remove PDF password

Steps

  1. Open Remove password and drop the locked PDF in.
  2. Type the password. If the file only has limits, such as no printing, leave the box empty.
  3. Press remove password and download. The new file opens without asking.
  4. Keep the original too, in case you need the locked version.

What this tool cannot do

It cannot guess, crack or bypass a password you do not have. If the file needs a password to open and you do not know it, no honest tool can open it for you.

Files with limits only

Some PDFs open without a password but forbid printing or copying. If you are allowed to use the file, the tool can save a copy without those limits. Only do this for documents you own or have permission to use.

Why remove a password?

Unlocked copies are easier to merge, split, edit and sign. Other tools in Dilia need an unlocked file for the same reason.

Keep sensitive files safe

An unlocked copy is readable by anyone who gets it. Delete it when you finish, or protect it again with a new password.

Questions

Is it legal to remove a password?

Removing a password from your own file with the password you hold is ordinary use. Do not use it to get into files that are not yours. We cannot give legal advice.

Is the password sent anywhere?

No. It is used in your browser only.

The file says it is not locked. Why?

Some PDFs are only protected by limits, or not protected at all. The tool tells you which.
