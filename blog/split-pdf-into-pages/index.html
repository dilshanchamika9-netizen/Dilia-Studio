How to Split a PDF Into Separate Pages or Files

You received one big PDF but need to send only part of it, or one file per chapter, invoice or student. Splitting does that. Dilia gives you several ways to cut, and shows which file each page will land in before you save.

Open Split PDF

Steps

  1. Open Split PDF and drop the file in. You will see all its pages.
  2. Choose how to split: every page, every N pages, custom ranges such as 1-3, 4-6, 7-, or odd and even pages.
  3. Look at the colours on the pages. Pages with the same colour go into the same file.
  4. Press download. Several files arrive together in one zip.

Splitting by ranges

Type ranges separated by commas. Each range becomes its own file. For example 1-3, 4-6, 7- makes three files, and the last one runs to the end of the document.

Other ways to cut

You can split by bookmarks, by size, or whenever a chosen piece of text appears, for example the word Invoice. Use the mode that matches how your document is built.

Only need some pages?

If you want to keep a few pages as one file, Extract pages is quicker than splitting. To remove pages instead, use Delete pages.

File names

New files are named from your original file name plus a number, so they stay easy to recognise.

Questions

Will the pages change?

No. Pages are copied exactly as they are.

Can I split a password protected file?

Remove the password first with Remove password, then split.

Is it uploaded?

No. Everything happens in your browser.
