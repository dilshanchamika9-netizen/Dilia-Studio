How to Redact a PDF So the Hidden Text Really Is Gone

People often hide names or numbers in a PDF by drawing a black box on top. The text underneath is still there, and anyone can select, copy or remove the box and read it. Real redaction removes the content itself.

Open Redact PDF

Steps

  1. Open Redact and drop your PDF in.
  2. Search for a word or number to find every place it appears, or draw boxes over areas by hand.
  3. Check each box on every page.
  4. Press redact and download. Redacted pages are saved as pictures.

Why covering is not enough

A shape over text only changes how the page looks. The text is still stored in the file. Copy and paste, search, or a PDF editor can reveal it. This has caused real leaks of documents that were thought to be censored.

What Dilia does differently

Redacted pages are turned into pictures with the black boxes burned in. The hidden text is no longer in the file, so it cannot be copied or recovered.

The trade-off

Pages that were redacted can no longer be searched or selected, and the file may be larger. Redact only the pages that need it by extracting them first, or accept that those pages become pictures.

Check the result

After saving, open the file, try to select text under a box, and search for the removed word. It should not be found.

Questions

Does Edit text remove the old text?

No. Edit text covers the old line. Use Redact for anything sensitive.

Can redaction be undone?

Not from the saved file. Keep your original in a safe place if you may need it.

Is it private?

Yes. Everything happens in your browser.
