How to Protect a PDF With a Password

A PDF with your ID, a contract or financial details should not sit in an inbox unprotected. A password stops anyone opening the file without it. Password protect PDF encrypts the file in your browser, so neither the file nor the password is sent anywhere.

Open Password protect PDF

Steps

  1. Open Password protect and drop your PDF in.
  2. Type a password of at least four characters, and type it again to confirm.
  3. Choose what people who open the file may do: print, copy text or change the file.
  4. Press protect and download. Test the new file by opening it before you send it.

Choose a strong password

Longer is better. Use a phrase of several words rather than a single word or a birthday. Send the password by a different route than the file, for example by message or phone call rather than the same email.

If you forget the password

Nobody can open the file. There is no reset, and Dilia cannot recover it because it never sees it. Keep the password somewhere safe, and keep an unprotected original if the file matters.

What the permission limits really do

The print, copy and change limits are respected by most PDF apps, but they are not a lock. Only the password needed to open the file is a real lock. Do not rely on limits alone for confidential files.

Removing the password later

If you know the password you can use Remove password to save an unlocked copy.

Questions

How strong is the encryption?

It uses AES-256, a standard strong method.

Will the recipient need special software?

No. Common PDF readers ask for the password when the file is opened.

Can the file still be compressed or edited?

Do those steps first, then protect the finished file last.
