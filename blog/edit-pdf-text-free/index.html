How to Edit Text in a PDF for Free

A PDF is designed to look the same everywhere, which is why it is hard to edit. You often only need to fix a date, a spelling mistake or a number. Edit PDF lets you click a line of text in the page and retype it, right in your browser.

Open Edit PDF

Steps

  1. Open Edit PDF and drop your file in.
  2. Choose the Edit text tool, then click the line you want to change. The line becomes an editable box.
  3. Type the new text. The size and colour of the original are kept. When the PDF allows it, the original font is used too.
  4. Check the page, then press save and download.

About fonts

When the PDF contains the font it used, Dilia reuses it, so the new text looks the same as the old. Some PDFs only contain the letters they actually show. If you type a letter that is not included, the line is drawn in the closest standard font (Sans, Serif or Mono) and the page tells you. You can also change the font yourself from the font menu.

Important: the old text is covered, not deleted

Edit text places a box over the old line and draws the new line on top. Someone who copies all the text from the saved file, or looks inside it with other software, may still find the old text. If the old text is sensitive, use the Redact tool, which removes it for good.

Adding new text and images

You can also add new text anywhere, place images, draw, highlight and add notes. These all work in the same page and are saved together.

When editing is not the right tool

If you need to rewrite a whole page or reflow paragraphs, it is better to change the original document, such as the Word file, and export a new PDF.

Questions

Can I edit a scanned PDF?

A scan is a picture of text, so there is no text to click. Run Recognise text first so the page contains real text.

Will the page layout move?

No. Only the line you edit changes. The rest of the page stays exactly as it was.

Is it free and private?

Yes. It runs in your browser and the file is not uploaded.
