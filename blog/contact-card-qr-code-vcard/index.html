How to Make a Contact Card QR Code for Your Business Card

Instead of making someone type your details, a contact card QR code lets them save you to their phone with one scan. It is a static code made in your browser, so there is no account and nothing expires.

Open Contact card QR

Steps

  1. Open Contact card QR and fill in your name, phone, email and any other fields you want shared.
  2. Keep it short. Fewer details make a simpler code that is easier to scan.
  3. Choose colours and add a logo if you like.
  4. Check the scan test, download the code and add it to your card or email signature.

Less is easier to scan

Every extra field makes the code denser. A name, one phone number and one email scan faster than a full address book entry. The page warns you if a code becomes too dense.

Think before you print a home address

A printed code can be scanned by anyone who sees it. Share only what you are happy for any stranger to have.

You cannot edit it later

A static code holds the details as they were when you made it. If your number changes, make a new code.

Questions

Is my information uploaded?

No. The code is made in your browser.

Does it work on iPhone and Android?

Yes. Both open a "new contact" screen when they scan a contact code.

Can I use accents or other alphabets?

Yes. Names with accents and non-Latin letters are supported.
