How to Read a QR Code From an Image or With Your Camera

A screenshot of a QR code or a code on a printed page cannot always be scanned by pointing a phone at it. QR code reader decodes the picture you give it and shows the contents as text first, so you can decide what to do. It runs in your browser.

Open QR code reader

Steps

  1. Open QR code reader.
  2. Drop a picture that contains a QR code, or use the camera option and point it at a code.
  3. Read what the code contains. A link is shown as text before you open it.
  4. Copy the text, or open the link only if you trust it.

Look before you open

Some codes lead to fake pages that ask for passwords or payments. Check the address in the result. If it does not match the company you expect, do not open it.

If the code is not found

Use a sharper, larger picture where the code fills a good part of the frame. Glare, folds and very small codes are the usual reasons for failure.

Camera permission

The live camera needs your permission, and the picture stays in your browser. You can use a saved image instead if you prefer.

Questions

Are my pictures uploaded?

No. The code is read inside your browser.

Can it read other barcodes?

This tool reads QR codes only.

Does it open links automatically?

No. It shows the text first and you choose.
