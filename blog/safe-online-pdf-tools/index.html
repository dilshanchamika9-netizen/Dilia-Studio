Are Online PDF Tools Safe? What Happens to Your File

A PDF often holds exactly the things you would not post publicly: contracts, payslips, ID copies, bank statements. Before you drop one onto a website, it helps to know what the site does with it.

See all tools

Two ways a tool can work

Some online tools upload your file to their server, process it there and send the result back. Others do all the work inside your browser, so the file never leaves your device. Both can be convenient. They are not the same in terms of risk.

What uploading means for you

Once a file is on someone else's server, you depend on their security and their promises about deleting it. Read the privacy policy to see how long files are kept and who can access them. If the file is sensitive, a tool that does not need to upload it removes that question.

How to check a tool yourself

Open your browser's developer tools, go to the Network tab, then run the tool. If a large request carrying your file goes out to a server, it is being uploaded. If nothing of that size leaves, the work is happening on your device. A site that works with your internet switched off after the page has loaded is also processing locally.

How Dilia works

The tools on Dilia that are marked as private process your files in your browser tab. The page says Processed in this tab. Nothing is uploaded. If we ever add a tool that needs a server, such as converting Word documents, we will say so clearly on that tool before you add a file.

Habits that help whatever tool you use

Use a protected copy for sensitive files, delete downloaded copies you no longer need, avoid public computers for important documents, and keep your original untouched.

Questions

Does in-browser mean it works offline?

Once the page has loaded, the processing does not need the internet. The first visit does.

Is any online tool completely risk free?

No. Choose the approach that exposes the least for the sensitivity of your file.

What about free tools that need an account?

An account means your files or activity may be linked to you. Check what the tool stores.
