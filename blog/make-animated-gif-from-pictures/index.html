How to Make an Animated GIF From Pictures

A GIF is a short loop of pictures. Make animated GIF joins your pictures in the order you set and saves one GIF file, all in your browser.

Open Make animated GIF

Steps

  1. Open Make animated GIF and add at least two pictures.
  2. Drag the cards into the order you want the frames to play.
  3. Set the time per frame in milliseconds, for example 500, and the width.
  4. Keep "Repeat forever" ticked for a loop, then press the button and download.

Keep the width modest

A GIF gets large quickly. A width around 480 pixels keeps the file small enough to share. A bigger width means a bigger file.

GIFs have a limited colour range

GIF can show only 256 colours per frame, so photos may look slightly grainy. That is a limit of the GIF type itself.

Make an existing GIF smaller

To shrink a GIF you already have, use Compress image. It reduces the colours and can scale the frames down.

Questions

How many pictures can I use?

As many as your device can handle. Phones do best with a few dozen.

Are my pictures uploaded?

No. The GIF is built in your browser.

Can I add text?

Not in this tool. Add text to each picture first with Meme generator.
