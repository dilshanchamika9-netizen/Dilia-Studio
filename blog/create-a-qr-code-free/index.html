How to Create a QR Code (Free, No Tracking, No Expiry)

A QR code lets people open a link or save a detail by pointing a camera at it. Dilia makes static codes: the information is written into the picture itself. There is no account, no tracking and nothing that can expire, and the code is made in your browser.

Open QR code generator

Steps

  1. Open QR code generator and choose what the code should do, for example open a link.
  2. Type or paste the information. The code appears right away.
  3. Open "Colours and shape" to change colours or the dot style. Add a logo or a frame if you like.
  4. Check the scan test result under the code, then download PNG, SVG, JPG or PDF.

Test it with a phone before you print

The page scans its own code and warns you if the colours are too close, the code is too dense or a logo is too big. Still, scan it with a phone before printing a hundred copies.

Use dark on light

Scanners read best with a dark code on a light background. A light code on a dark background is harder for some phones.

Which file to download

Use PNG for screens and documents. Use SVG when the code will be printed large, such as a poster, because it stays sharp at any size. The PDF holds a high-resolution picture.

Static means it cannot be changed later

The link is part of the picture. If the page address changes, the printed code will still point to the old one. That is the trade for having no tracking and no subscription.

Questions

Does the code expire?

No. A static code works as long as the page it points to exists.

Do you track scans?

No. The code goes straight to your information and does not pass through Dilia.

Is it free for business use?

Yes. There is no watermark and no limit on codes.
