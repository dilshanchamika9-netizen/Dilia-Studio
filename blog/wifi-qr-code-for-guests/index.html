How to Make a Wi-Fi QR Code So Guests Can Join Instantly

Reading out a long Wi-Fi password is slow and easy to get wrong. A Wi-Fi QR code lets guests join by scanning. The code holds the network name and password, and it is made in your browser, so the password is not sent to anyone.

Open Wi-Fi QR code

Steps

  1. Open Wi-Fi QR code and type the exact network name (SSID).
  2. Type the password and choose the security type. Most home routers use WPA / WPA2 / WPA3.
  3. Tick "Hidden network" only if the network name is not shown in the list.
  4. Download the code and print it, or put it on a stand or frame.

Names and passwords are case sensitive

A capital letter in the wrong place stops the connection. Copy the name and password exactly from your router page.

Anyone who sees the code can join

The code contains the password. Put it where guests can see it, not on a public wall, or set up a separate guest network on your router.

If you change the password

The printed code keeps the old one. Make a new code and replace the print.

Questions

Is my password uploaded?

No. The code is made in your browser and nothing is sent.

Which phones can scan it?

Recent iPhones and Android phones read Wi-Fi codes with the normal camera.

Can I add a frame?

Yes. Choose a frame with text such as "Scan to join Wi-Fi".
