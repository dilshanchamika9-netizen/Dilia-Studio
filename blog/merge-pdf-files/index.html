How to Merge PDF Files Into One (Free, No Upload)

You have a contract in one file, the signed page in another and a price list in a third. Sending three attachments looks messy and is easy to get wrong. Merging them into one PDF takes about a minute, and with Dilia it happens inside your browser, so the files never leave your device.

Open Merge PDF

Steps

  1. Open Merge PDF and drop your files onto the page, or choose them from your device. You can add as many as you need.
  2. Drag the file cards into the order you want. The first card becomes the first pages of the new PDF.
  3. Check the page count shown on the right. It should equal the sum of your files.
  4. Type a name for the new file, then press the download button.

Check the order before you download

The most common mistake is a file in the wrong place, for example the signature page ending up before the contract. Use the sort button if your files are named in order, such as 01, 02, 03, and look at the order once more before saving.

What if one file is password protected?

A locked file cannot be merged until it is opened. If you know the password, use Remove password first, then merge the unlocked copy.

What if the result is too big to email?

Merging adds the sizes together. Most email services accept roughly 20 to 25 MB per message, so a merged file of that size may bounce. Compress the merged file, or send it in two parts.

Merging pages from inside one file

If you only need some pages from a PDF, extract those pages first, then merge them with the others. This avoids sending pages the other person does not need.

Questions

Is there a limit on how many files I can merge?

The limit is your device. Very large files use more memory, so on a phone it is best to merge a few at a time.

Are my files uploaded anywhere?

No. The merge runs in your browser tab. Closing the tab removes the files from memory.

Will the quality change?

No. Pages are copied as they are. Text, images and fonts are not re-drawn.
