About the quiz maker

Each question has up to four answers and one right answer. In play mode, tapping an answer shows the right one at once and counts a point if you were right. As a host, press Show answer to reveal it without scoring.

Save as a file gives you a small file you can send to someone. Loading a file only accepts the quiz format and is checked before it is used. Nothing is sent anywhere.
