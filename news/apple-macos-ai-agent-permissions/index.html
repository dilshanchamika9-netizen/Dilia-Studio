Apple tightens Mac permissions as AI agents ask for full access

macOS 27.3 splits one broad setting into two and shows a menu bar light when one app is controlling another. Existing permissions keep working.

Dilia Pulse deskMonday 16 November 20262 min read

Apple has changed how Mac users grant powerful permissions to apps, a response to AI agents that ask for broad access to files and other software so they can work on a user's behalf.

The company outlined the changes to developers on 16 November as part of the second beta of macOS 27.3. It had warned in early October that it would tighten these controls, citing the growing number of increasingly capable and autonomous agents.

What changes

The main change splits a single setting, previously called Device Control and Data Access, into two: System and App Protection Override, and Accessibility. The aim is to make it obvious when an app is being allowed to get around the Mac's built-in protections, rather than burying that inside a broader permission.

A new indicator in the menu bar will show when one application is controlling another through the override, so users can see an agent at work.

What does not change

The update does not block AI agents. Apps that already hold these permissions keep them, and the new approval flow applies to fresh requests. Security teams will still need to review which tools already have wide access. Users can check current permissions in System Settings under Privacy and Security.
