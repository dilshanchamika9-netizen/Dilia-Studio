Trip booklet

Turn a trip from your Trip planner into a printable file for the journey. Print it or save it as a PDF.

No trips found in this browser yet. Build one in the Trip planner, then come back here. Trips are saved per browser, so open this page on the same device.

How it works

The booklet is built from the trips saved in this browser by the Trip planner, so nothing is uploaded. It lists every day with times, places, notes and booking references, then a table of all references. Contacts you type here are saved in this browser only. Print it and keep a paper copy in case your phone fails.
