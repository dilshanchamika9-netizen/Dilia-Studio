Document expiry wallet

Keep track of when passports, IDs, visas and insurance run out, before it ruins a trip.

Enter only a type, an owner name and the expiry date. Do not type passport or ID numbers. Everything stays in this browser.

Check against a trip

Packing listTrip planner

How it works

Documents are sorted by how soon they expire. The check compares each expiry with the end of your trip plus the extra months you enter. Many countries require a passport to stay valid for a set time after arrival or departure, often three or six months, but the rule differs by country and nationality. Always confirm with the official government or embassy source of your destination.

The reminder file adds one all-day event 90 days before each expiry, so you can import it into any calendar app.
