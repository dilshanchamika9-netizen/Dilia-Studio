## 5. Phase 1 tools (working, 17 Nov 2026)
- Shared helpers: `assets/kit.js` (toasts, ranges parser, ZIP writer, thumbnails, PDF opener, drop handling). Merge keeps its own copy (`merge.js`), untouched.
- `assets/ptool.js` = one engine for single-PDF tools, chosen by `<body data-tool>`: split, delete, extract, rotate, reorder, pdf2img. `assets/img2pdf.js` = Images to PDF.
- The seven pages (`split/delete/extract/rotate/reorder/pdf2img/img2pdf.html`) are GENERATED by `python3 dev/make-pages.py` from one template. Edit the TOOLS table there, re-run, commit the html. `merge.html` is hand-written.
- Behaviour: delete/extract/pdf2img select pages by click or typed ranges (two-way synced); split = every page / every N / custom ranges (one file per range, ZIP if more than 1 file); rotate edits the original in place (rotation adds to existing); delete/extract/reorder/split copy pages into a fresh PDF so deleted content is not left inside the file.
- Images to PDF: JPG/PNG embedded untouched; WebP/GIF/BMP/AVIF, rotated images and sideways phone photos (EXIF) are redrawn on a canvas. Page size same-as-image (capped 1000 pt) / A4 / Letter, orientation, margin. HEIC not supported by browsers (message tells user).
- PDF to images: PNG or JPG, 100/150/200/300 DPI (capped at 9000 px side, 80 MP), 1 page = single image, more = ZIP.
- Known limits: copying pages drops bookmarks/form fields (delete, extract, reorder, split); password-protected PDFs are refused with a message; very large PDFs (300+ pages) and Safari/iPhone not tested.
- Tested (Playwright + pypdf): 70+ checks, outputs verified page by page, errors for locked/broken/non-PDF files, mobile layout.

## 7. Phase 2b tools (working, 17 Nov 2026)
- `assets/filetool.js` (modes protect / unlock / compress; pages `protect.html`, `unlock.html`, `compress.html`, generated by `dev/make-pages.py`, kind `file`).
- Protect/Unlock use qpdf compiled to WebAssembly, self-hosted: `assets/vendor/qpdf.js` + `qpdf.wasm` (1.3 MB, qpdf Apache-2.0, wrapper ISC, licence in `qpdf-LICENSE.txt`). AES-256. Print/copy/edit limits use a random owner password; only the open password is a real lock. Unlock needs the known password (cannot crack). Limits-only files unlock without a password.
- Compress re-encodes plain-JPEG photos inside the PDF (Light q.82 no resize / Medium q.70 max 1800 px / Strong q.55 max 1200 px) and saves with object streams. Text/vector untouched. If the result is not at least 2% smaller nothing is downloaded and a message explains. Not handled: PNG/Flate images, JPEGs wrapped in ASCII85, CMYK/masked images (left as they are).
- qpdf prints some messages to the browser console on expected failures (wrong password, damaged file). These are not site errors.
- Tested with real encrypted/decrypted files checked by the native qpdf CLI and pypdf.

## 9. OCR and Redact (working, 17 Nov 2026)
- OCR (`filetool.js` mode ocr, tesseract.js 7.0.0 self-hosted in `assets/vendor/ocr/`, 6.8 MB, English only): adds an invisible text layer, page looks identical. Skips pages that already have text. Two passes (300 and 100 DPI) because Tesseract drops very large glyphs. 90 s start timeout. Rotated pages handled.
- Redact (`editor.js` tool `redact`, page `redact.html`): drag boxes or "Mark all matches" (text search, scans need hand boxes). On save, every page with a redaction is rendered to a 200 DPI JPEG with the box burned in, and the file is rebuilt in a fresh PDFDocument, so the original text is not in the file bytes. Other pages keep their text. Limits: English OCR only, redacted pages lose text and links, a phrase split across lines is not matched.
