# Security policy

Dilia processes files in your browser. Files are not uploaded.

## Report a vulnerability
Use GitHub private reporting: Security tab > "Report a vulnerability". Do not post details in a public issue.
Include the page, the steps, and a sample file if the bug involves one. We aim to acknowledge within 5 working days.

## Scope
In scope: the Dilia site and its code in this repository, including file handling, privacy claims and bundled libraries.
Out of scope: social-engineering, denial of service by huge files on your own device, third-party sites.
