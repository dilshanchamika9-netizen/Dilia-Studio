How it works

  • Type the names (3 to 50). Optionally add pairs who must not draw each other.
  • Press Make the draw.
  • Pass the device: each person taps their name, sees their person, then hides it.
  • The draw is never saved. Leaving the page clears it.

    About the secret santa generator

    Nobody draws themselves, and pairs you list under "do not pair" never draw each other. The draw is made fairly among all valid arrangements. Only the names you typed are saved in this browser; the result of the draw lives in memory until you leave the page.

    The organiser can open the full list at the end, which spoils the surprise for the organiser.
