How it works

Your trips are kept only in this browser. Clearing the browser's site data deletes them, so download a backup before a big trip; the backup file can be restored on any device. The calendar file uses the times as you typed them (local time at the place), so check times in your calendar app if your phone is set to a different time zone.

Nothing is uploaded and there is no account. Booking references stay on your device.
