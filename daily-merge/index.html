How to play

  • Swipe, or use the arrow keys (or W A S D).
  • Two equal tiles that touch join into one: 2 + 2 = 4.
  • A new tile appears after every move.
  • Reach 2048. The game ends when no move is left.
  • Everyone gets the same new tiles in the same order today. No undo, one game a day.

About daily merge

One new game every day at midnight where you are. Everyone gets the same new tiles in the same order, so the best players really are the best. Your score is final when no move is left.

Your game and best score stay in this browser. Nothing is sent anywhere.
