Use it as your Windows PDF app

  1. In Chrome or Edge, press Install (the download icon in the toolbar or the address bar).
  2. Open Windows Settings > Apps > Default apps, type .pdf, and choose Dilia PDF.
  3. Double-click any PDF in File Explorer. It opens here, also with no internet.

A free PDF reader that keeps your files private

Dilia PDF reads files in your browser. Nothing is uploaded, and scripts inside PDFs never run. Web links in a PDF ask before they open. Files attached inside a PDF are never opened by Dilia.

  • Tabs for several PDFs, recent files and favourites
  • Page thumbnails, bookmarks, layers and attachments
  • Search with match case and whole words
  • Fit width, fit page, two-page view, rotate, night reading, read mode and full screen
  • Select and copy text, print page ranges, measure distances and areas
  • Read aloud with the voices on your device
