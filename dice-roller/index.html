    About the dice roller

    Every roll is a fair random pick between 1 and the number of sides, so each face has the same chance. Use d6 for board games, d20 for role-playing games, or any number from 2 to 1000 sides.

    Nothing is sent anywhere. Rolls are not saved when you leave the page.
